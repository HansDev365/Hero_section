This project is a simple **one-page responsive landing page** built using **HTML and CSS only**.
It was created as part of a web development assignment focusing on layout, spacing, and responsive design.

## 🎯 Project Goal

The goal of this project was to design a **Hero section** with a clear **Call to Action (CTA)** that encourages users to interact with the page.

## ✨ Features

* Responsive design (works on mobile and desktop)
* Clean hero section layout
* Clear Call to Action (CTA) button
* Semantic HTML structure
* Styled using custom CSS

## 🛠 Technologies Used

* HTML5
* CSS3
